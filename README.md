# 租房管理系统

租房管理工作台，包含房源/房间、租户、入住退房、日常维护、收支账单、报销批次和合同文件管理。

## 运行

需要 Node.js 20 或更高版本，无需安装第三方依赖。

    npm start

打开 http://localhost:3000。租房工作台入口为 `/`，兼容 `/zufang.html`。

生产环境必须通过 `ADMIN_PASSWORD` 设置独立的高强度密码，凭据只放在服务器环境变量或环境文件中，不要提交到仓库。

## 数据存储

租房数据默认保存在 `data/` 下的租房 JSON 文件，并由 `rental-db.js` 在支持 `node:sqlite` 时同步到 `data/rental.sqlite`。生产环境请备份整个 `data/` 目录（包括维护图片和合同文件目录）。

本目录只保留租房页面、租房接口依赖和租房部署文件；原 `HouseRental` 目录继续作为旧版本回退备份。后端 `server.js` 目前仍保留少量历史兼容路由，确认线上迁移完成后再单独剥离，以降低数据迁移风险。
